        Облачное подключение
        
        

          API с совместимым Chat Completions. Облако включается только выбранной
          командой. Ключ не сохраняется в базе или журнале.
        

      

    

  

  
    
Открыть проект

    

      Путь к папке одной игры. Определим движок и расположение текста без
      интернета. Доступные сценарии Ren’Py соберём автоматически; для остальных
      форматов покажем отчёт. Архивы не распаковываются.
    

    
    

      
    

  
  
    
Догрузить текст

    

      Выберите один или несколько файлов либо укажите полные пути, каждый на
      новой строке. JSON: массив записей source / translation или дерево строк.
      CSV: столбец source.
    

    
    

      
    

  
  
    

    

    
  
  
    
Экспорт перевода

    

      Исходный игровой файл сохраняется. Для существующего Ren’Py слоя
      экспортируется .rpy с теми же идентификаторами; для остальных форматов —
      JSON-корпус. Проверьте экспорт перед установкой в игру.
