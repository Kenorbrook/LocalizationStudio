# Venice Uncensored 1.2: регистрация, оплата и подключение

Проверено 12 октября 2026 года. Инструкция для прямого Venice API и модели `venice-uncensored-1-2`. Доступность оплаты и лимиты конкретного аккаунта проверяются в его кабинете. Реальная регистрация, платёж и запрос с пользовательским ключом при подготовке этой инструкции не выполнялись.

## Что потребуется

Аккаунт Venice, API-ключ типа **Inference Only**, доступный баланс для API и интернет с доступом к `api.venice.ai`. Скачивать модель, покупать видеокарту или устанавливать Ollama для облачного режима не требуется. Это запросы на серверы провайдера: туда отправляются оригинальные тексты, выбранный контекст и правила проекта.

Подписка на веб-чат и использование API — разные вещи. По текущей документации ключ можно создать до пополнения; платным запросам нужен расходуемый баланс. Для первого опыта достаточно доступных API-кредитов, покупать Pro только ради этой инструкции не требуется. Бонусы и условия подписок смотрите в своём кабинете, бесплатный API-баланс здесь не обещается. [Официальная инструкция по ключам](https://docs.venice.ai/guides/getting-started/generating-api-key).

## 1. Регистрация и проверка доступа из РФ

1. Откройте [Venice](https://venice.ai/) и зарегистрируйтесь доступным на сайте способом. Выполните подтверждение аккаунта, если его запросит сервис.
2. Откройте [API Dashboard](https://venice.ai/settings/api). Проверьте, что видны баланс, создание ключа и пополнение.
3. До оплаты уточните доступность для вашего места проживания и способа оплаты. В опубликованных [условиях](https://cdn.venice.ai/legal/tos) и [FAQ](https://venice.ai/faqs/all) не нашлось отдельного актуального подтверждения обслуживания всех пользователей из РФ. Отсутствие явного списка стран не гарантирует доступ.

Нужно различать доступность сайта у вашего провайдера, допуск аккаунта к API и возможность оплаты. Успешное открытие страницы не подтверждает остальные пункты. Если кабинет сообщает о региональном ограничении, уточните его у поддержки через контакты сайта до пополнения. Не указывайте выдуманную страну или платёжные данные. Смена маршрута соединения не меняет условия обслуживания аккаунта.

Российскую карту не стоит считать рабочим способом оплаты зарубежного сервиса: приостановка международной работы карт Visa/Mastercard, выпущенных в РФ, описана самими платёжными системами. Карта «Мир» не подтверждена Venice как поддерживаемая. Если у вас есть законно оформленная иностранная карта, её приём всё равно зависит от банка и платёжного кабинета. [Visa](https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.18871.html).

## 2. Пополнение баланса

Откройте [API Dashboard](https://venice.ai/settings/api). Вверху справа, рядом с **New API Key**, есть небольшая кнопка со значком **Purchase Credits** (подпись может появляться только при наведении). Она открывает окно **Add credits**. На проверенном интерфейсе предложены $10, $25, $50, $100 и **Enter a custom amount**. Кнопка **Upgrade** в этом окне ведёт к подписке; для разового пополнения выбирайте сумму кредитов. После выбора кабинет покажет доступные способы оплаты.

Для первого теста выбирайте небольшое разовое пополнение API-кредитов, без автопополнения. Точный минимум покажет кабинет; фиксированную минимальную сумму для обычного API-пополнения официальные страницы, проверенные здесь, не установили.

Согласно [FAQ Venice](https://venice.ai/faqs/all), кредиты покупаются за **USD или USDC**. Используйте именно раздел кредитов/API: покупка подписки не обязательно равнозначна нужному пополнению.

- **USD:** платёж картой, если кабинет предлагает его и принимает вашу карту.
- **USDC:** официальный криптовалютный способ пополнения, если он доступен аккаунту. Сеть, сумму и адрес берите из текущей формы оплаты. Название USDC не означает, что подходит любая сеть. Не отправляйте USDT вместо USDC и не переводите средства на адрес из чужой инструкции. Учитывайте комиссию выбранной сети и доступность используемого платёжного провайдера для вас.

После платежа убедитесь, что баланс появился именно в API Dashboard. Покупать VVV, заниматься стейкингом или приобретать DIEM для обычного платного API-подключения не нужно.

У Venice также есть [x402 — доступ с кошельком без API-ключа](https://docs.venice.ai/guides/integrations/x402-venice-api). Это другой протокол авторизации. Нынешняя Localization Studio использует Bearer API-ключ, поэтому x402 напрямую к ней не подключается. Для приложения нужен обычный аккаунт с ключом и кредитами.

## 3. Создание API-ключа

В [API Settings](https://venice.ai/settings/api) нажмите **Generate New API Key**:

1. Description: `Localization Studio`.
2. API Key Type: **Inference Only**, без административных полномочий.
3. При желании задайте срок действия.
4. В Epoch Consumption Limits поставьте небольшой лимит USD на 24-часовую эпоху, например $1 для начала. Не отключайте расход USD, если пополняли именно USD-баланс: нулевой лимит заблокирует запросы даже при наличии средств.
5. Создайте ключ и сразу скопируйте его: полный секрет показывается один раз.

В поле приложения вставляется только сам ключ — без `Bearer`, кавычек и пробелов. Не отправляйте его в чат и не сохраняйте в файлах проекта. Приложение хранит ключ в Windows Credential Manager. При утрате создайте новый; при раскрытии отзовите старый. [Инструкция Venice](https://docs.venice.ai/guides/getting-started/generating-api-key).

## 4. Проверка ключа вне приложения

Необязательная проверка в PowerShell. Ключ вводится скрыто; скрипт не записывает его на диск:

```powershell
$secureKey = Read-Host 'Venice API key' -AsSecureString
$keyPointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secureKey)
try {
    $veniceKey = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($keyPointer)
    $veniceHeaders = @{ Authorization = 'Bearer ' + $veniceKey }
    Invoke-RestMethod -Uri 'https://api.venice.ai/api/v1/api_keys/rate_limits' -Headers $veniceHeaders
} finally {
    [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($keyPointer)
    Remove-Variable veniceKey,veniceHeaders -ErrorAction SilentlyContinue
    $secureKey.Dispose()
}
```

Этот маршрут бесплатен и проверяет авторизацию, баланс и ограничения. Смотрите `data.accessPermitted`. Простое получение `/models` недостаточно: каталог доступен без ключа. Успешная авторизация ещё не проверяет качество генерации. [Проверка ключа](https://docs.venice.ai/guides/getting-started/generating-api-key).

## 5. Подключение к Localization Studio

Запустите обновлённое приложение и откройте проект. В настройках «Облачное подключение» укажите:

| Поле | Значение |
| --- | --- |
| HTTPS API URL | `https://api.venice.ai/api/v1` |
| Название облачной модели | `venice-uncensored-1-2` |
| API-ключ | Созданный ключ Venice |
| Контекст для первого теста | `32768` |
| Лимит ответа | `4096` |
| Максимум запросов | `50` для небольшого тестового проекта |

Сохраните настройки и выберите облачный API в списке исполнителей. `/chat/completions` к адресу не добавляйте — приложение добавляет путь само. Наш адаптер отключает дополнительный системный текст Venice и веб-поиск; контекст поступает из проекта. [Официальный Quickstart](https://docs.venice.ai/getting-started/quick-start).

Сначала используйте отдельный небольшой тестовый корпус. На странице проекта оставьте включёнными предварительный анализ и автоматический подбор сведений. При запуске перевода сначала выполняется анализ всех импортированных строк, потом перевод. В «Справочник и неясные места» проверьте вопросы ИИ. Можно запустить только анализ отдельной кнопкой и проверить справочник до перевода.

Лимит запросов действует отдельно на каждую задачу: анализ и перевод имеют собственные счётчики, редактура делает несколько вызовов. Это не денежный лимит. Денежный предел задавайте на стороне Venice. При исчерпании лимита или недоступности сервиса задача останавливается с сохранением результатов; готовые блоки анализа используются из кэша.

## 6. Стоимость и ошибки

В текущем [прайсе Venice](https://docs.venice.ai/overview/pricing) для этой модели указаны **$0,20 за миллион входных токенов и $0,90 за миллион выходных**, контекст 128K. Пример: 10 млн входных и 1 млн выходных токенов стоят около **$2,90** по этим ставкам. Это пример объёма, не смета игры. Во вход входят повторяющиеся инструкции, соседние реплики и справочник; анализ, перевод и редактура оплачиваются отдельно. Не приравнивайте число игровых слов к числу оплаченных токенов.

| Ошибка | Что проверить |
| --- | --- |
| 401 | Полный ключ, отсутствие кавычек/пробелов, срок действия и отзыв ключа |
| 402 | Доступный баланс и отдельный лимит расхода ключа, разрешён ли расход USD |
| 403 | Доступ аккаунта/модели, ограничения сервиса; уточнить у поддержки |
| 429 | Ограничение скорости; подождать и продолжить сохранённую задачу |
| Нет связи | Доступность API из вашей сети; браузер и приложение могут использовать разные настройки прокси |
| Ответ обрезан / неверный JSON | Лимит ответа и контекст; продолжить после исправления параметров |

Локальная Ollama по-прежнему обращается напрямую к `127.0.0.1:11434` и не зависит от VPN. Облачному API требуется рабочее внешнее соединение. Без реального ключа и небольшого пробного запроса невозможно подтвердить доступ вашего аккаунта, скорость и качество перевода именно этой модели.
