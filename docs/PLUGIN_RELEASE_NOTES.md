# Hermes plugin 1.0.1

Отчёт теперь явно сообщает, что Hermes не импортировал текст, не изменил справочник и не установил перевод в игру. Добавлен переход к поиску текста и импорту. Действия переименованы в получение отчёта, чтобы не смешивать исследование файлов и анализ персонажей.

Это необязательный помощник. Локальный перевод, справочник и редактура встроены в Studio и работают без него. Пакет совместим с Plugin API 1 / Studio 0.6.0+; новая страница маршрута находится в Studio 0.6.1.

Настройки модели, среда и отчёты сохраняются. Обновляется только пакет интеграции; веса модели и среда Hermes повторно не скачиваются.
