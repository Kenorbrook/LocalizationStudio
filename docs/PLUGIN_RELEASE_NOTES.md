# Hermes plugin 1.0.0

Первый самостоятельный пакет Hermes для Localization Studio 0.6.0+.

- Собственная версия, проверка обновлений, установка и откат без обновления Studio.
- Исследование файлов и разбор ошибок добавляются в интерфейс только при включении плагина.
- Модель, профиль Ollama, установленная среда Hermes и пользовательские отчёты сохраняются.
- Встроенный автоповтор ошибок остаётся функцией Studio.

Этот ZIP устанавливается через «Плагины → Установить из ZIP». Он не содержит приложение или веса модели. Hermes Agent внутри среды: 0.22.5; версия пакета интеграции: 1.0.0.
