# Стандарт перевода Localization Studio

- Передавать смысл, намерение, тон, степень грубости и откровенности оригинала без смягчения и без добавления подробностей.
- Писать естественно; идиомы переводить по смыслу. Соседние реплики помогают понять строку, но не включаются в её перевод.
- Имена, термины, роли и особенности речи хранить отдельно для каждого проекта. Не переносить персонажей между играми.
- Сохранять теги, переменные и структуру. Отказ модели, предупреждение или пересказ не являются переводом.
- Локальный перевод и локальная редактура — основной маршрут. Облако подключается только по выбору пользователя.
- Редактор исправляет доказуемые ошибки; неопределённые случаи оставляет для человека. Формальная проверка не доказывает литературное качество.
- Сохранять исходники и кэш. Готовые переводы не переписывать автоматически; экспортировать в отдельный файл и проверять в игре.
- В приложении прогресс и журнал показываются внутри окна, без дополнительной консоли. Отдельный CLI-скрипт `translation_tools/run_translation.ps1` открывает видимое окно PowerShell.
- Ollama вызывается напрямую по `127.0.0.1:11434`, без обязательного VPN. Скачивание модели требует подключения, её последующий локальный запуск — нет.
- Дообучение требует проверенного корпуса и независимого теста; автоматически сгенерированный перевод не считать эталоном.

По умолчанию используется литературный профиль `translation_tools/local_literary_profile.json`.
Выбирайте установленную модель в интерфейсе. Для Ren’Py CLI требуется уже подготовленный слой `game/tl/russian`.
Ручной перевод и игровые проверки необходимы перед распространением локализации.
