Localization Studio 0.2.1 — предварительная версия Windows x64.

- Проверка GitHub Releases, проверенное скачивание и установка обновлений с резервной копией, перезапуском и продолжением очередей.
- Отключаемые автоматическая проверка, скачивание и установка в свободное от задач время. Без сети перевод, импорт и правки продолжают работать.
- Отдельные лимиты новых запусков и продолжения, счётчик строк или времени с остатком.
- Повтор ошибок отдельными очередями с собственными параметрами, включая массовый повтор.
- Контекст, история процесса, папки пометок и сохранённых оригиналов, защита ручных правок.
- Разделение модулей, единое форматирование и архитектурные проверки.

Распакуйте весь архив. Первый переход с 0.1.0 выполняется вручную: той версии ещё не была доступна кнопка обновлений. Новая версия сможет устанавливать последующие опубликованные релизы.
Поддержка полного цикла локализации реальных игровых движков и литературное качество не считаются подтверждёнными этой сборкой. Перед установкой отключите MCP-клиент; активные ручные правки необходимо сохранить.
