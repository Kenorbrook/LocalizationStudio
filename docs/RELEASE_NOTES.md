Localization Studio 0.4.3 — Windows x64.

Исправлена остановка всей очереди из-за ошибки отдельной строки:

- HTTP 500 от локального запроса Ollama отправляет строку в раздел «Ошибки»; обработчик продолжает остальные строки.
- Проблемную строку можно повторить отдельно с другими параметрами контекста и лимита ответа. Она не считается переведённой, а итог задачи указывает, что есть ошибки для проверки.
- Нехватка памяти в ответе Ollama распознаётся и отображается понятным сообщением.
- Отключение Ollama, ошибки соединения и недоступность сервиса по-прежнему ставят очередь на паузу с сохранением прогресса. Облачные HTTP 500 не меняют поведения.

Проверка включает автоматические тесты локального HTTP 500 и ошибки внутри HTTP 200, продолжения соседних строк и повторного запуска с другим контекстом. В собранном EXE на нейтральном корпусе дополнительно проверяется, что ошибка одной строки не останавливает следующую и остаётся доступной для ручного повтора. Реальные запросы к моделям для этих проверок не выполняются.

Перед обновлением сохраните несохранённые правки и отключите MCP-клиент. Проекты и очереди сохраняются; перед заменой файлов создаётся резервная копия.

Для ручной установки скачайте `LocalizationStudio-v0.4.3-windows-x64.zip`, полностью закройте приложение с выгрузкой и замените файлы программы из архива, сохранив свою папку `data`. Контрольная сумма архива находится в `SHA256SUMS.txt`.
