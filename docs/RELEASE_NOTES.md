Localization Studio 0.5.1 — Windows x64.

Переработано управление плагинами:

- Отдельный пункт «Плагины» внизу левой панели. Каталог открывается в основной области: поиск по названию и назначению, категории, избранное и фильтры состояния.
- Быстрые переключатели сохраняются сразу. Исправлена ошибка, из-за которой отключение Hermes не сохранялось. Если запись не удалась, состояние возвращается с объяснением.
- Параметры модели находятся в отдельном окне и не перезаписывают переключатель. Отключение запрещает новые исследования; для прекращения уже начатого есть «Остановить».
- Исследование Hermes находится в «Файлы и источники» проекта, разбор — в «Ошибки». Для недоступных действий показывается причина.
- Встроенные автоповторы доступны в ошибках и настройках перевода. Они работают без установленного или включённого Hermes.

Проверены интерфейс собранного EXE, сохранение и отказ записи переключателя, отмена черновика, фокус, прокрутка, фильтры и поиск на 100 записях. Для проверки масштаба использовались один настоящий адаптер и 99 тестовых описаний без установки дополнительных плагинов и запросов к модели.

Среда Hermes и модели в ZIP не входят. Для Hermes по-прежнему нужна модель Ollama с инструментами и контекстом от 64 000 токенов; автоповторы этим требованием не ограничены.

Для версии 0.4.4+ используйте обновление через шестерёнку: скачиваются только изменённые файлы. Для первой установки скачайте `LocalizationStudio-v0.5.1-windows-x64.zip`. При ручной замене закройте приложение с выгрузкой и сохраните папку `data`. Контрольная сумма — в `SHA256SUMS.txt`. `update-files.json` и `file-*.gz` приложение обрабатывает само.
