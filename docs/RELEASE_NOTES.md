Localization Studio 0.5.2 — Windows x64.

Модель для Hermes теперь можно подготовить кнопкой в приложении:

- «Плагины → Hermes Agent → Настроить»: явный список установленных моделей Ollama с размером и числом параметров. Если Ollama недоступна, показываются причина и кнопка обновления списка.
- Выберите модель, при необходимости измените контекст в «Параметры модели» и нажмите «Подготовить для Hermes». Будет создан отдельный профиль Ollama с этим контекстом. Выбор сохраняется автоматически; команды PowerShell не нужны.
- Веса используются повторно. Исходная модель, параметры переводчика и включение плагина не меняются. Подготовка не загружает модель в GPU и не проверяет, поместится ли она в память.
- Поддержка инструментов и максимального контекста проверяется до создания. Готовый профиль проверяется по фактическому num_ctx. Повторная подготовка использует проверенный профиль; чужие и изменённые модели не перезаписываются.
- При отмене или ошибке прежний выбор Hermes сохраняется. Проверка подключения и исследование теперь отклоняют неподготовленный контекст, вместо попытки передать неподдерживаемый параметр через OpenAI-совместимый API.

Проверены 291 автоматический тест и сценарии в собранном EXE. Создание профиля дополнительно проверено с настоящим Ollama в изолированном хранилище: контекст изменён только у нового профиля, blobs весов общие, исходные параметры сохранены, загруженных для генерации моделей — 0. Использовался нейтральный GGUF с метаданными; реальная игровая модель и её скорость не тестировались.

Обновитесь через шестерёнку: начиная с 0.4.4 скачиваются только изменённые файлы. Для первой установки — `LocalizationStudio-v0.5.2-windows-x64.zip`. При ручной замене закройте приложение с выгрузкой и сохраните папку `data`. Контрольная сумма — в `SHA256SUMS.txt`. `update-files.json` и `file-*.gz` приложение обрабатывает само.
