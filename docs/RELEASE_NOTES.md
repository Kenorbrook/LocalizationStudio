# Localization Studio 0.8.6

- В «Очередь и история» можно запустить независимую задачу со своей моделью и одновременно переводить новые строки и редактировать готовые.
- «Разделить очередь» переносит часть незапущенных строк другому исполнителю. Если позволяет выбранный объём, граница проходит между сценами или файлами.
- У активных очередей отдельные прогресс, пауза, продолжение, отмена и журнал.

## 0.8.5

- При временном сбое API очередь повторяет запрос с нарастающей задержкой и учитывает `Retry-After`. Карточка задачи показывает причину и время до повтора.
- Автовозобновление включено по умолчанию. Его можно отключить в настройках API-ключа.

## 0.8.4

- Добавление API-ключа и управление списком теперь открываются в отдельных окнах.
- Действие при закрытии можно изменить напрямую в настройках приложения.
- Сокращены сообщения об установке обновлений.

## 0.8.3

- Архив и управление проектами доступны рядом со списком проектов. Повторное открытие папки возвращает архивный проект с его данными или сообщает, что проект уже добавлен.
- Новые журналы и загруженные через приложение файлы лежат в скрытой папке `.localization-studio` внутри проекта. Удаление проекта очищает его служебную папку. Архивирование сохраняет её.

## 0.8.2

- Строка сразу уходит из списка ошибок при постановке на повтор. Если повтор отменён или снова не удался, ошибка возвращается. История попыток сохраняется.

## 0.8.1

- В списке «Исполнитель» видны API-ключи, доступные для проекта. После выбора ключа модель можно выбрать в том же разделе.
- Под кнопкой продолжения показаны имя API-ключа и модель, которые будут использоваться в очереди.

## 0.8.0

- Активная задача видна в шапке приложения. Нажатие открывает нужный проект. Счётчик строк, скорость, сообщение об ошибке и модель показаны отдельно.
- API-ключи управляются в настройках приложения. Можно использовать несколько подключений, назначать их всем или выбранным проектам и копировать скрытый ключ.
- Приложение загружает доступные модели через API. Модель выбирается для проекта, есть ручной ввод ID для сервисов без каталога.
- При открытии проекта доступен стандартный диалог выбора папки. В текстовых полях и выделяемом тексте есть контекстное меню.
