Localization Studio 0.4.1 — Windows x64.

Обновление включает изменения после версии 0.2.9:

- Переработан интерфейс: навигация проекта, текст и текущая задача разделены; настройки проекта собраны в отдельном окне с разделами. Редкие параметры и облачные подключения убраны из основного рабочего экрана, пояснения доступны через «?».
- Локальная модель используется по умолчанию; облачные модели включаются отдельно в настройках проекта.
- Добавлен анализ импортированного проекта: персонажи, отношения, термины и сцены с цитатами оригинала. Справочник автоматически подбирается к переводу; неясные выводы доступны для ручной проверки.
- Исправлен зависающий запуск задач: ошибки запуска обработчика переводят очередь на паузу с возможностью продолжения.
- MCP `app_ui_state` и `app_screenshot` получают состояние интерфейса и свежие снимки самого приложения без переключения окон, мыши или системных клавиш. Те же операции доступны через CLI; скрытый режим запуска не забирает фокус.

Проверка версии: 214 автоматических тестов и проверка MCP, CLI и свежих снимков в собранном Windows EXE на нейтральном корпусе.

Перед обновлением сохраните несохранённые правки и отключите MCP-клиент. Проекты и очереди сохраняются; перед заменой файлов создаётся резервная копия.

Для ручной установки скачайте `LocalizationStudio-v0.4.1-windows-x64.zip`, полностью закройте приложение с выгрузкой и замените файлы программы из архива, сохранив свою папку `data`. Контрольная сумма архива находится в `SHA256SUMS.txt`. После обновления переподключите MCP-клиент для появления новых инструментов.
