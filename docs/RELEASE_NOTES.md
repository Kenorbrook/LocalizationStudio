Localization Studio 0.5.0 — Windows x64.

Добавлен необязательный плагин Hermes Agent:

- Шестерёнка → «Плагины»: включение, отдельное скачивание и установка, выбор модели Ollama, проверка подключения, журнал и остановка. По умолчанию выключен; в ZIP среда Hermes не входит и при обновлении Studio заново не скачивается.
- «ИИ-помощник» проекта исследует расположение игровых текстов и объясняет ошибки. Доступ ограничен чтением текущего проекта; терминал, браузер и изменение игры агенту не предоставляются. Отчёты сохраняются отдельно по проектам.
- Нужна модель с поддержкой инструментов и контекстом не менее 64 000 токенов. Этот параметр отделён от перевода; большой контекст требует памяти. Проверка подключения не загружает модель и не гарантирует, что она поместится в память. Перед исследованием приостановите перевод и дождитесь завершения текущего запроса.
- В том же окне есть встроенное автоматическое восстановление ошибок памяти и лимитов — работает без Hermes. Включается отдельно для проекта, подбирает параметры только для неудачных строк, максимум два дополнительных прохода и до 200 строк на задание. Старые ошибки можно запустить кнопкой. Ручные правки, сохранённые оригиналы, пауза и аварийные остановки защищены.

Проверены тесты очереди, границы MCP, отмена и изоляция проектов. Реальный закреплённый Hermes проверен со Studio MCP и тестовым локальным сервером ответов; качество конкретной модели Ollama и размещение её контекста в памяти требуют проверки на вашем компьютере. Интерфейс проверен в скрытом EXE на нейтральном проекте без управления рабочим столом.

Для установленной версии 0.4.4+ используйте обновление через шестерёнку: скачиваются только изменённые файлы, Lingua используется повторно. Для первой установки скачайте `LocalizationStudio-v0.5.0-windows-x64.zip`. При ручной замене закройте приложение с выгрузкой и сохраните папку `data`. Контрольная сумма — в `SHA256SUMS.txt`. При переходе напрямую с 0.4.3 и более ранних версий полный ZIP понадобится один раз; `update-files.json` и `file-*.gz` приложение обрабатывает само.
