# Localization Studio 0.7.4

Исправлен случай, когда модель упрямо повторяет одну латинскую букву внутри русского слова, даже после подсказки.

- `перепиcываю` с латинской c автоматически исправляется на `переписываю` с русской с, без дополнительного запроса к модели.
- Исправляются только одна-две визуально похожие латинские буквы в преимущественно кириллическом слове. На каждую заменяемую букву требуется минимум четыре кириллические.
- Исходные имена и слова, защищённые теги, переменные, идентификаторы с цифрами или подчёркиваниями сохраняются. Короткие и неоднозначные слова не переписываются механически.
- Преимущественно латинское `Сemen` не принимается за исправленный русский перевод: для таких слов остаётся полноценный повтор с подсказкой или ручная правка.
- После замены повторяются проверки тегов, переменных, переносов, отказов и смешения алфавитов. Исправленные слова перечисляются в истории перевода.

Нормализация букв не проверяет литературный смысл всей фразы. Проекты, переводы и версии плагинов сохраняются. Новый механизм применяется после обновления и следующего запуска обработчика; уже сохранённые записи автоматически не переписываются.
