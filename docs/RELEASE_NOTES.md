# Localization Studio 0.6.1

На странице «Перевод игры» появился понятный локальный маршрут: поиск и импорт текста → перевод → редактура → встраивание.

- Каждый этап показывает текущее состояние проекта и конкретное действие. Количество импортированных строк не выдаётся за полноту извлечения всей игры.
- Подготовка перевода и редактуры предлагает установленные модели Ollama и явно запускает локальную задачу без облачного API и без Hermes. Выбор относится только к этому запуску; пресет проекта сохраняется.
- Незавершённая очередь направляет к её продолжению/завершению, без смены модели и автоматического перезапуска.
- Список необходимых компонентов отделяет встроенные функции, Ollama с моделью и необязательные плагины.
- Встраивание честно отмечено как ещё не реализованное. Экспорт объясняет разницу между JSON-корпусом и существующим слоем Ren’Py; это не установка готовой игры.
- Поиск файлов и сбор персонажей получили разные названия. Журнал анализа больше не обещает отдельный PowerShell.

Hermes 1.0.1 публикуется отдельным пакетом: его отчёт объясняет, что импорт и установка не выполнены, и даёт переход к поиску текста. Уже установленный плагин обновляется отдельно в «Плагины → Версия и обновления».
