# Localization Studio 0.7.3

Экран ошибок показывает проблемные строки, а не отдельные повторения одной ошибки.

- Для строки отображается одна карточка с последней причиной. Предыдущие неудачные попытки сохранены в раскрываемой истории. Две разные строки с одинаковым текстом остаются разными карточками. Счётчик и пагинация считают строки.
- На карточке доступны «Контекст», «История», «Править вручную», обычный повтор и «Исправить с подсказкой» для локальных ошибок смешения букв.
- Ручной перевод открывается вместе с контекстом сцены. Обновление списка не заменяет поле ввода и не сбрасывает черновик. После сохранения все открытые ошибки этой строки закрываются, а ручная правка защищается от ИИ.
- Для новых ошибок смешения алфавитов сохраняется отклонённый ответ модели: его можно раскрыть и открыть для ручного исправления. В старых ошибках такого ответа могло не сохраниться; исходник и контекст доступны в любом случае.
- «Исправить с подсказкой» создаёт отдельную локальную очередь на модели проекта: модель получает конкретный дефект и коды Unicode похожих букв. Новый кэш отделяет запрос от прежних попыток. Контекст и лимиты модели автоматически не увеличиваются.
- Кнопка «Исправить смешение букв» выбирает подходящие локальные строки всего проекта, каждую по одному разу. Повторное нажатие не создаёт ещё одну очередь для уже ожидающих исправления строк.
- Новая очередь ждёт завершения текущих задач. Если предыдущая очередь успела исправить строку, дополнительная генерация для неё пропускается. Неудачные ответы остаются ошибками; история не удаляется.

Данные проектов, готовые переводы, очередь и отдельные версии плагинов сохраняются. Новый интерфейс появляется после обновления приложения. Проверка формата не заменяет литературную редактуру.
