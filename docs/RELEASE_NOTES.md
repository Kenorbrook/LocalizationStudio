Localization Studio 0.4.2 — Windows x64.

Исправлен запуск перевода из приложения:

- Отдельная консоль больше не открывается при переводе, анализе и редактуре. Прогресс и журнал доступны внутри приложения.
- Если обработчик завершился неожиданно, задача переходит на паузу с понятной причиной. Приложение проверяет реальный процесс и убирает зависший статус работающего обработчика.
- Продолжение использует прежнюю очередь и сохранённые результаты. Повторный запуск не допускается, пока предыдущий обработчик ещё выполняет запрос.
- Самостоятельный Ren’Py CLI по-прежнему открывает отдельное окно PowerShell.

Проверка включает автоматические тесты и сценарий в собранном EXE на нейтральном корпусе: запуск без консоли, принудительное завершение только тестового обработчика, отображение паузы и продолжение оставшихся строк без изменения уже сохранённого перевода. Реальные запросы к моделям для этой проверки не выполняются.

Перед обновлением сохраните несохранённые правки и отключите MCP-клиент. Проекты и очереди сохраняются; перед заменой файлов создаётся резервная копия.

Для ручной установки скачайте `LocalizationStudio-v0.4.2-windows-x64.zip`, полностью закройте приложение с выгрузкой и замените файлы программы из архива, сохранив свою папку `data`. Контрольная сумма архива находится в `SHA256SUMS.txt`.
