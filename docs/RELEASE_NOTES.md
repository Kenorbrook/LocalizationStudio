# Localization Studio 0.7.2

Автоматическое исправление слов, в которых локальная модель смешала латиницу и кириллицу.

- При ошибке вроде «Теst» модель получает исходную строку, отклонённый ответ и указание перевести проблемное слово заново. Добавлена одна ограниченная попытка только для локального перевода. Облачных дополнительных запросов нет.
- Исправление не сводится к слепой замене похожих букв: новый ответ модели полностью проверяется заново, включая теги, переменные, переносы и отказы. Если он снова неверен, строка остаётся в «Ошибках», остальные строки продолжаются.
- Если для исправления не хватает контекста, сначала убираются дальние справочные реплики. Исходная строка и правила проекта сохраняются. Если и этого недостаточно, причина явно указывается в ошибке.
- Сообщение теперь поясняет, что дефект находится в ответе модели, а не в показанном оригинале, и показывает Unicode-коды букв.
- Старые ошибочные фрагменты кэша при повторном переводе генерируются заново; исправные фрагменты используются как прежде. Сохранённые переводы не переписываются автоматически.
- Очередь, проекты, история и отдельные версии плагинов сохраняются. Исправление вступает в силу после обновления приложения и следующего запуска обработчика.

Для уже накопленных ошибок после обновления выберите их повторный перевод в разделе «Ошибки». Запущенная очередь не заменяется на лету. Изменение не гарантирует литературную точность каждого ответа; обычная редактура остаётся отдельным этапом.
