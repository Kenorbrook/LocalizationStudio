Localization Studio 0.2.7 — предварительная версия Windows x64.

В настройках появился блок «О приложении»: версия, кнопка «Сообщить об ошибке», инструкция и значок GitHub с исходным кодом. Ссылки открываются в системном браузере. Интернет используется только после нажатия; локальный перевод остаётся автономным.

Перед обновлением сохраните несохранённые правки и отключите MCP-клиент. Проекты и очереди сохраняются; перед заменой файлов создаётся резервная копия.
