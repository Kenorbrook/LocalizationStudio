Localization Studio 0.4.4 — Windows x64.

Обновления больше не требуют повторной загрузки неизменённых библиотек:

- Встроенный обновлятор проверяет установленные файлы по SHA-256 и скачивает только изменённые, отсутствующие или повреждённые.
- Lingua, занимающая около 96 МБ в архиве, используется повторно, пока её содержимое не изменилось. Определение языков сохраняется полностью.
- Окно обновления показывает объём скачивания и повторно используемых файлов.
- Исправлена потеря фокуса при вводе причины сохранения оригинала: фоновое обновление больше не извлекает неизменённые карточки из страницы, черновик причины сохраняется.
- «Другой язык» / «Авторский приём» теперь заполняют причину; отдельная кнопка «Сохранить оригинал» сохраняет её и показывает подтверждение.
- Перед заменой проверяется вся новая сборка. Сохранены резервная копия, откат при неудачной установке, проекты, переводы, настройки и состояние очереди.

**Для установки скачайте `LocalizationStudio-v0.4.4-windows-x64.zip`.** Полностью закройте приложение с выгрузкой и замените файлы программы из архива, сохранив свою папку `data`. Контрольная сумма находится в `SHA256SUMS.txt`.

**При переходе с 0.4.3 и более ранних версий полный архив понадобится ещё один раз:** старый обновлятор не умеет скачивать отдельные файлы. После установки 0.4.4 следующие обновления через приложение будут загружать только изменения.

`update-files.json` и `file-*.gz` — служебные файлы обновлятора. Вручную их скачивать и распаковывать не нужно. Новая версия становится общедоступной только после загрузки всех файлов релиза.

Проверки включают выборочную загрузку, восстановление отсутствующей и повреждённой библиотеки, контрольные суммы, ограничение распаковки, запрет изменения пользовательских данных и откат установки. Полный путь проверки, загрузки, установки и перезапуска дополнительно проверяется в скрытой копии собранного EXE на нейтральном проекте без перехвата управления компьютером.
