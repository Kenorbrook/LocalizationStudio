Localization Studio 0.2.8 — предварительная версия Windows x64.

В папках пометок настройки больше не появляются сами при обновлении прогресса. Кнопка «Отправить на редактуру с новыми параметрами» открывает отдельное окно с моделью, контекстом, лимитами и инструкцией редактору. После закрытия окно остаётся закрытым.

Перед обновлением сохраните несохранённые правки и отключите MCP-клиент. Проекты и очереди сохраняются; перед заменой файлов создаётся резервная копия.
