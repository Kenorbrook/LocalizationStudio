Localization Studio 0.5.3 — Windows x64.

Исправлено ожидание медленного локального Hermes:

- Прежний общий лимит 7 минут мог обрывать работающую модель после чтения проекта. Теперь применяется ограниченный бюджет до 30 минут с ограничением шагов и длины ответа.
- Во время работы показываются этап, прошедшее время и число полученных символов. В журнале каждый новый запуск отделён от установки; при тайм-ауте показывается последний этап. Остановка остаётся доступной.
- Для служебного анализа запрашивается отключение расширенного thinking. Сводка структуры и ошибок передаётся компактнее, с путями, признаками движка и явным обозначением усечённых списков. Обычный перевод и выбранный контекст модели не меняются.
- Ошибка записи прогресса не прерывает результат.

Проверены 298 автоматических тестов, собранный EXE, настоящий Hermes с нейтральным проектом Studio MCP и тестовым сервером ответов, а также остановка дочернего процесса. Тестовые запросы не загружали игровую модель в GPU. Скорость конкретной локальной модели по-прежнему зависит от оборудования и размера контекста.

Обновитесь через шестерёнку: начиная с 0.4.4 скачиваются только изменённые файлы. Для первой установки — `LocalizationStudio-v0.5.3-windows-x64.zip`. При ручной замене закройте приложение с выгрузкой и сохраните папку `data`. Контрольная сумма — в `SHA256SUMS.txt`. `update-files.json` и `file-*.gz` приложение обрабатывает само.
