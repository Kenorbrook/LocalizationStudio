# Localization Studio 0.6.0

Плагины теперь обновляются отдельно от приложения и могут расширять интерфейс.

- Hermes вынесен в самостоятельный пакет 1.0.0: собственные обновления и откат без перезапуска Studio.
- Элементы Hermes в проекте и на экране ошибок появляются только при включении плагина.
- Плагины могут добавлять меню, вкладки и блоки настроек, действия над строками и глобальные темы. Отключение убирает их элементы, стили, подписки и таймеры.
- В каталоге есть установка ZIP с предварительным просмотром возможностей, версия пакета, проверка обновлений и возврат предыдущей версии.
- Автоповторы ошибок остаются встроенной функцией и работают без Hermes.
- Сохраняются настройки, профиль модели Ollama, уже установленная среда Hermes и отчёты. Переводы и очередь не перезапускаются.

Нужно один раз обновить Studio до 0.6.0 для нового механизма. Следующие изменения в рамках API плагинов устанавливаются через раздел «Плагины». Изменение самого ядра или API по-прежнему требует обновления приложения.
