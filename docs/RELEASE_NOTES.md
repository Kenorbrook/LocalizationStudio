# Localization Studio 0.7.1

Исправлены остановки локального перевода при долгом ответе или обрыве отдельного запроса Ollama.

- Локальная генерация ожидается до 10 минут вместо 3. Время ожидания облачного API не меняется.
- После тайм-аута или сброса соединения выполняется отдельная короткая проверка сервиса. Если Ollama доступна, проблемная строка остаётся в «Ошибках», а перевод/редактура следующих строк продолжается. Неудачный ответ не считается переводом.
- Если проверка Ollama не проходит, очередь сохраняется на паузе с конкретной причиной и ручным продолжением после восстановления связи.
- Индикатор связи обновляется каждые 30 секунд через лёгкую проверку версии сервиса. Список моделей и поля редактирования не перезагружаются; генерация для проверки не запускается.
- Готовые переводы, очередь и кэш сохраняются. Уже работающий обработчик не заменяется на лету.

Проверено на нейтральных сценариях: тайм-аут, сброс соединения, HTTP 500, настоящая недоступность сервиса и повтор только ошибочной строки. Игровые модели и реальные проекты для тестовой генерации не используются. Плагины сохраняют свои отдельные версии.
