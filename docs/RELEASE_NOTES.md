# Localization Studio 0.7.5

Исправлено исчезновение проекта из списка после завершения перевода.

- Обновление состояния больше не архивирует проекты автоматически и не переключает выбранный проект. Завершённый перевод остаётся в списке после перезапуска приложения.
- Готовность строк не подменяет этапы редактуры, проверки и встраивания перевода в игру.
- Скрыть или архивировать проект по-прежнему можно явным действием в управлении проектами. Ранее скрытые проекты можно восстановить из архива.
- Переводы, история, очередь, исходники и версии плагинов сохраняются.
