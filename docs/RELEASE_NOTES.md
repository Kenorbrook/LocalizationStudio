Localization Studio 0.4.5 — Windows x64.

Исправлено сохранение оригинала из папки ручной проверки:

- После ручного «Сохранить оригинал» снимается пометка «Ручная проверка». Строка сразу исчезает из этой папки, а оригинал и причина остаются в «Оригинал без перевода».
- При первом открытии новой версии исправляются старые автоматические языковые пометки, оставшиеся до сохранения оригинала. Пометки, поставленные позднее, и непроверенные ручные пометки сохраняются.
- Для сохранённых оригиналов доступна кнопка «Снять пометку». Пометки «Брак» не снимаются автоматически.
- Автоматическое сохранение оригинала само по себе не считается ручным подтверждением. Конфликт версии или неудачный запрос не снимает пометку.

Проверено снятие пометки и исчезновение строки из папки, сохранение причины и оригинала, согласованность очереди, восстановление старого случая и защита более поздних пометок. Интерфейс дополнительно проверяется в скрытом собранном EXE на нейтральном проекте без управления рабочим столом.

С версии 0.4.4 обновлятор скачивает только изменённые файлы, повторно используя неизменённую Lingua. Обновитесь через настройки приложения.

Для первой или ручной установки скачайте `LocalizationStudio-v0.4.5-windows-x64.zip`, полностью закройте приложение с выгрузкой и замените файлы программы, сохранив свою папку `data`. Контрольная сумма — в `SHA256SUMS.txt`. При переходе напрямую с 0.4.3 и более ранних версий полный архив понадобится один раз. `update-files.json` и `file-*.gz` приложение обрабатывает само.
