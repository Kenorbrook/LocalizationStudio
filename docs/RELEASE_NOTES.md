# Localization Studio 0.7.0

Первый полный локальный цикл Ren’Py: отдельная копия → штатное извлечение текста → локальный перевод и редактура → сборка и выбор языка.

- Самостоятельный плагин «Ren’Py: локализация игры» 1.0.0. Подготовка рядом с поиском текста, сборка и запуск — на шаге встраивания. Модель выбирается из установленных в Ollama.
- Оригинальная папка и переводы сохраняются. Для копии создаётся отдельный проект. Однозначные переводы переносятся, спорные требуют ручной проверки.
- Два режима: переключатель в меню либо выбор языка перед запуском через Studio. Проверяются компиляция, lint, загрузка строк, смена языка и шрифт. Доступен откат сборки.
- Обычная очередь Studio, остановка на ошибках и пометках, без автоматического продолжения после перезапуска. Облако и Hermes не требуются.
- Общие точки расширения для модулей движков. Ren’Py обновляется отдельно; установленный Hermes не заменяется обновлением программы.
- Исправлен импорт блоков Ren’Py с озвучкой и сохранение контекста сцены по ссылке на исходный скрипт.

Полный цикл проверен на нейтральной игре Ren’Py 8.5.3. В конкретной игре нужно проверить сцены и отображение; динамический текст, изображения и нестандартные экраны могут потребовать адаптации. Для других движков обзор показывает фактические ограничения.
