Localization Studio 0.2.4 — предварительная версия Windows x64.

- Версия и кнопка настроек закреплены снизу левой панели.
- Параметры обновлений перенесены в отдельное окно с закреплённой кнопкой закрытия.
- Кнопка «Обновить» появляется, когда найдена новая версия; пояснение об источнике скрыто до этого момента.
- Чекбоксы расположены рядом с подписями.

Настройки автоматических обновлений сохраняются; по умолчанию сетевые действия выключены. Перед установкой сохраните ручные правки и отключите MCP-клиент. Проекты и очереди сохраняются.
