# Типовые дефекты перевода

## Смешение алфавитов: «Сemen» вместо русского слова

Зафиксирован повторяющийся случай: модель пишет `Сemen`, где первая `С`
кириллическая (`U+0421`), а `emen` — латинские буквы. Встречаются и другие
варианты с кириллической `е` или латинскими буквами внутри слова «сперма».
Визуального сходства недостаточно: проверять нужно символы ответа модели,
а не английский оригинал, показанный над ошибкой.

Нейтральный контрольный пример:

- Исходник: `Sample: semen.`
- Дефектный ответ: `Образец: Сemen.`
- Исправление: `Образец: сперма.`

Замена только `С` на латинскую `C` даёт `Cemen` и не переводит слово.
В значении семенной жидкости `semen` переводится как «сперма» или «семя»
с учётом контекста. Это не правило для механической замены `juice`: напиток
должен остаться напитком. Имена, идентификаторы и защищённые токены нужно
сверять с оригиналом и правилами конкретного проекта.

С версии 0.7.2 локальный перевод получает одну дополнительную попытку
исправления: исходник, отклонённый ответ и конкретный дефект передаются модели.
Новый ответ заново проходит проверки; неправильный ответ не считается готовым.
Для исторических записей требуется отдельная проверка: они могли сохраниться
до появления защиты и не должны автоматически переписываться при обновлении.

При исправлении исторических записей:

1. Снять согласованную резервную копию базы и изменяемого словаря проекта.
2. Проверить исходник, сцену, актуальную ревизию и несохранённые правки.
3. Записать точечную правку через обычный API сохранения, оставив прежнюю
   версию в истории. Не выдавать исправление одного слова за полную редактуру.
4. Защитить ручное исправление от перезаписи обработчиком и повторно проверить
   оставшиеся сохранённые записи. Не перезапускать всю очередь ради этих строк.

Регрессия: `tests/test_script_repair.py` проверяет точное написание `Сemen`,
другие смешанные варианты, исправный русский текст и защищённые переменные.
