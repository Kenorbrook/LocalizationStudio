# Локальная локализация Ren’Py

Нужны Studio 0.7.0+, включённый плагин «Ren’Py: локализация игры» и установленная модель Ollama. Hermes и облачный API не требуются.

1. Создайте проект по папке распакованной Windows-игры. Запустите поиск файлов, если движок ещё не определён.
2. На первом шаге обзора нажмите **Подготовить копию Ren’Py**. Укажите новую папку рядом с оригиналом или другую новую папку. Нужно место для полной копии игры.
3. Модуль запускает штатную команду перевода движка в копии. Studio открывает отдельный проект со слоем `game/tl/studio_russian`. Исходные скрипты не используются для обратной записи.
4. Выберите установленную локальную модель и способ переключения языка. Нажмите **Перевести → проверить → собрать**. Обычная очередь Studio выполняет локальный перевод и редактуру.
5. При ошибках, паузе, браке или ручных пометках сборка останавливается. Разберите их на соответствующих экранах; затем повторно запустите цикл или нажмите **Собрать из готовых переводов**. Уже обработанные строки сохраняются. Открытие Studio не возобновляет цикл автоматически.
6. После сборки запустите копию на русском или исходном языке кнопками модуля. Проверьте диалоги, выборы, меню, шрифты и переходы между сценами.

## Переключение языка

- **В меню игры:** модуль добавляет собственный переключатель в стандартный экран `preferences`. Если подходящий экран не найден, используется отдельный экран поверх интерфейса. Он не зависит от фильтра списка языков по проценту переведённых строк.
- **Перед запуском через Studio:** кнопки запуска русского и оригинала задают язык для выбранного запуска. Внутриигровой переключатель в этом режиме не добавляется.

Исходная папка не меняется. Сохранения копии хранятся в её `game/saves`, одинаково при запуске через Studio и напрямую. Последнюю сборку можно отменить; переводы в базе сохраняются. Если файлы копии изменены вне Studio, повторная сборка и откат останавливаются. Перед сборкой и откатом копия должна быть закрыта; Studio не завершает игру сама.

## Проверки и ограничения

Используется собственный Windows runtime игры, без подмены версии движка. Проверяются компиляция, `lint`, соответствие загруженных строк штатным идентификаторам, доступность кириллического шрифта и смена языка на уровне движка. DejaVu Sans применяется к основным стилям русского языка. Ошибка проверок возвращает предыдущие файлы.

Переводы переносятся только из исходного проекта этой игры по однозначному совпадению оригинала, говорящего и сцены. Разные варианты и помеченные строки не выбираются автоматически: новый проект получает ручную пометку.

Это первый адаптер полного цикла. Обнаружение рассчитано на Windows-дистрибутивы Ren’Py 7 и 8 с собственным `.py` launcher и `python.exe`. Нейтральный цикл проверяется на Ren’Py 8.5.3. Отсутствующий runtime, изменённый launcher или неподдерживаемые ресурсы вызывают остановку с объяснением.

Динамические строки, текст в изображениях, индивидуальные стили и нестандартные экраны могут потребовать адаптации. Проверка загрузки движком не заменяет прохождение игры и литературную оценку. Игра исполняет собственные скрипты: используйте доверенную игру.

## Обновления и тесты

Модуль обновляется отдельно в **Плагины → Ren’Py → Версия и обновления**. Первое обновление Studio до 0.7.0 добавляет точки интерфейса и начальный пакет; последующие обновления приложения не заменяют выбранное поколение плагина.

`tools/check_renpy_cycle.py` создаёт нейтральную игру на закреплённом официальном SDK и проверяет генерацию слоя, оба способа сборки, откат и неизменность исходников. Переводы заданы тестом: игровые модели Ollama не вызываются. `tests/test_renpy_plugin.py` проверяет порядок локальных задач, неоднозначности, паузы, границы файлов и сбои записи. UI проверяется в скрытом EXE через inspection без перехвата рабочего стола.
