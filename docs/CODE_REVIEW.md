# Ревью архитектуры — 2026-10-06

Проверены границы Python-модулей, последовательность обновления интерфейса, пути ресурсов, упаковка, остановка обработчика и структура публичного репозитория. Это ревью сопровождается изменениями кода, а не заявлением об отсутствии всех дефектов.

| Проблема | Последствие | Изменение |
| --- | --- | --- |
| Большая цепочка команд и HTTP-маршрутов в `app.py` | Добавление функции требует изменения общей точки входа; обработчик задач зависит от API | Явные реестры команд и чтения, отдельные доменные обработчики, транспорт и запуск задач |
| Последовательное переопределение `refresh`, `renderRows`, `settings`, `loadRows` | Порядок расширений неочевиден, трудно найти владельца поведения | Именованные обработчики жизненного цикла и один загрузчик карточек |
| Проверка версии списка отдельным запросом перед его загрузкой | При обновлении изменившегося списка выполняются два одинаковых чтения | Один запрос, проверка принадлежности ответа экрану, переиспользование неизменившихся карточек |
| Код и стили внутри HTML, очень длинные строки | Неудобные ревью и конфликты при правках | Отдельные ресурсы и закреплённое форматирование |
| Схема, миграции и извлечение текста внутри хранилища | Обязанности не отделены | `schema.py`, `extraction.py`, `serialization.py`, `paths.py` |
| Тесты и описание сборки среди runtime-файлов | Структура не объясняет назначение файлов | Отдельные `tests/`, `packaging/`, `docs/`, `src/ui/`; обновлены CI и упаковка |
| Обработчик может завершиться между проверкой и `TerminateProcess` | Ложное сообщение «Отказано в доступе» при закрытии | При неудаче проверяется завершение через тот же открытый handle; настоящий отказ остаётся ошибкой |
| Отрицательная длина HTTP-запроса | Чтение может ждать окончания потока вместо немедленного отказа | Отрицательная длина отклоняется; добавлена проверка транспорта |

После разделения база и форматы кэша не меняются. Импортированные переводы и параметры существующих задач не переписываются. Полный цикл локализации реальных игровых движков этим ревью не подтверждается.

Проверки изменения: 155 автоматических тестов, закреплённое форматирование Python и UI, сборка обоих Windows EXE, полный сценарий интерфейса на нейтральном корпусе и проверка установленной версии на чтение. Рабочая задача продолжена с прежними параметрами после резервного копирования и обновления приложения.

## Дополнительное ревью и рефакторинг — 2026-10-06

Закрыты четыре перечисленных долга:

- `Store` разделён на транзакционные репозитории с явными зависимостями; фасад сохраняет прежние сигнатуры. SQL и правила изменения данных находятся у владельцев операций. Схема и формат кэша не менялись.
- Общее состояние UI выделено в `state.js`; устранены отдельные изменяемые глобальные переменные проекта, строк, задачи, редакторов и страницы. Native bridge читает тот же набор несохранённых правок.
- Убраны обёртки `showView`, обработчиков переключения проектов, MCP и перелистывания. Навигация имеет именованные события; страницы описывают собственное перелистывание. Старый дублирующий обработчик папки ошибок удалён.
- Извлечение разделено на адаптеры Ren’Py, JSON/JSONL, CSV и TXT с явным реестром. Защитные ограничения экспорта сохранены; запись непосредственно в игру не включена.

Проверки: 177 автоматических тестов, Black и Prettier, сборка приложения, обработчика и установщика обновлений, 123 проверки интерфейса собранного EXE на нейтральном корпусе. В том числе переключение страниц текста и папок, сохранение активного редактора, защита ручных правок, очереди, контекст, архивирование и удаление тестового проекта.

Остаются ограниченные общие функции между обычными UI-скриптами и совместимость старого Ren’Py CLI через `paths.py`. Это явные ограничения, а не заявление об отсутствии архитектурного долга или подтверждение локализации всех движков.
