# Чтение окна без управления рабочим столом

Нужна запущенная Localization Studio 0.4.1 или новее. MCP-клиент и окно должны использовать одну базу (`--db`). После обновления уже подключённый stdio MCP нужно переподключить, чтобы он получил новые инструменты.

Для установки проверенной локальной сборки без прерывания работы: `.venv\Scripts\python.exe tools\install_when_closed.py`. Помощник до 12 часов ждёт естественного завершения установленного GUI и MCP/обработчиков, затем сохраняет резервную копию, устанавливает сборку и запускает её в трее без активации. Он не закрывает процессы и не посылает команды окнам. Пока приложение работает или просто скрыто в трей, установка ждёт.

- `app_ui_state` — текущие проект, файл, раздел, открытые диалоги, видимые тексты, значения полей, варианты списков, координаты контролов, несохранённые записи.
- `app_screenshot` — новый PNG из WebView2 и состояние интерфейса. Изображение возвращается стандартным блоком MCP `image`.
- Существующие `list_projects`, `project_status`, `read_block`, `read_record` читают данные проекта, независимо от текущего экрана.

CLI из установленной папки (PowerShell):

```powershell
.\LocalizationWorker.exe --inspect state
.\LocalizationWorker.exe --inspect screenshot --output D:\LocalizationStudio\reports\current-ui.png
```

Укажите `--db <полный путь к studio.sqlite3>`, если используется другая база. CLI пишет JSON в stdout, ошибки в stderr с кодом 1. Существующий файл снимка не перезаписывается. Источник для разработки: `.venv\Scripts\python.exe src\inspection_client.py state` или `screenshot --output ...`.

Запросы не запускают новое окно, не активируют приложение, не меняют фокус или положение мыши. Канал доступен только на localhost с токеном приложения. Ключи и пароли скрываются в JSON; при открытом значении секретного поля снимок отклоняется. В JSON не передаются исходный HTML, токен сессии или сырые настройки провайдера.

PNG охватывает текущий viewport встроенного интерфейса. Нативные окна Windows, другие приложения и невидимые разделы в снимок не входят. JSON содержит видимые контролы, включая доступные прокруткой; длинный текст ограничен 150 000 символами с `text_truncated`. Состояние и PNG снимаются последовательно, а не одной транзакцией. Если WebView2 не отвечает, возвращается ошибка; старые изображения не используются. Скрытый режим проверен в EXE; состояние свёрнутого окна зависит от доступности renderer и не исправляется активацией окна.

`LocalizationStudio.exe --hidden` запускает приложение в трее без активации. Проверка на отдельном нейтральном корпусе: `.venv\Scripts\python.exe tools\check_app_inspection.py`. Она создаёт скрытый экземпляр, сравнивает два свежих снимка, проверяет CLI/MCP, отсутствие изменений записей и сохранение активного окна. Рабочая база не используется.
