# Ren’Py 1.0.0

Первый модуль полного локального цикла Windows-игр Ren’Py. Требуется Studio 0.7.0+.

- Отдельная копия игры, штатный слой перевода и отдельный проект Studio.
- Перенос однозначных переводов той же игры; спорные совпадения требуют проверки.
- Локальный перевод → редактура → сборка через очереди Studio. Hermes и облачный API не нужны.
- Переключатель языка в меню или выбор перед запуском через Studio.
- Проверки компиляции, lint, загрузки переводов, смены языка и кириллического шрифта. Ошибки и пометки блокируют сборку.
- Откат последней сборки с сохранением переводов; защита исходной папки и внешних изменений копии.

Динамические строки, изображения и нестандартный интерфейс могут потребовать адаптации. Проверка нейтральной игры не заменяет проверку сцен и внешнего вида конкретной игры. Модуль использует собственный runtime игры и не обновляет её движок.
