# 0.6.0

- Самостоятельные версионируемые плагины с обновлением и откатом.
- Plugin UI API 1: точки меню и настроек, вкладки проекта, действия строк, глобальные темы и очистка при отключении.
- Hermes 1.0.0 отделён от ядра; автоповторы ошибок работают независимо.

# Изменения

## 0.5.3 — 2026-10-25

- Исправлено преждевременное прерывание медленных локальных исследований по общему лимиту 7 минут. Новый ограниченный бюджет учитывает длительные ответы; число шагов и объём ответа ограничены.
- В ходе работы показываются этап, прошедшее время и число полученных символов. Запуски отделены в журнале; ошибка тайм-аута сообщает последний этап.
- Для служебного анализа Ollama запрашивается отключение расширенного thinking. Настройки обычного перевода не меняются.
- Структура игры и план ошибок передаются агенту компактно, с сохранением признаков движка, путей и явным обозначением усечённых списков. Полный просмотр структуры в интерфейсе остаётся доступен.
- Ошибка записи прогресса не прерывает ответ модели. Проверены настоящее исполнение Hermes с нейтральным MCP и тестовым сервером модели, длительное ожидание, тайм-аут и остановка дочернего процесса.

## 0.5.2 — 2026-10-25

- В настройках Hermes появился явный список установленных моделей с размером, числом параметров, обновлением списка и объяснением недоступности Ollama.
- Кнопка «Подготовить для Hermes» берёт выбранную модель и контекст, создаёт отдельный профиль Ollama через локальный API и автоматически сохраняет выбор. Команды PowerShell, повторная загрузка весов и изменение исходной модели не нужны.
- Подготовка проверяет поддержку инструментов и контекста, повторно использует проверенные профили и не перезаписывает чужие или изменённые. При отмене и ошибке прежние параметры Hermes сохраняются.
- Проверка подключения и запуск исследования проверяют контекст, заданный непосредственно в профиле Ollama. Убрана передача `num_ctx` через неподдерживаемый параметр OpenAI-совместимого запроса.

## 0.5.1 — 2026-10-25

- Плагины вынесены в отдельный раздел внизу левой панели: поиск, категории, избранное и фильтры по состоянию. Настройки выбранного плагина открываются отдельно; список не пересоздаётся при фоновом обновлении.
- Включение и отключение сохраняются сразу. Исправлено исчезновение кнопки сохранения при отключении Hermes. Ошибка записи возвращает переключатель в прежнее положение и показывает причину.
- Отключение доступно во время работы и запрещает новые исследования, сохраняя уже начатое. Немедленная остановка остаётся отдельным действием. Сохранение параметров модели не меняет состояние включения.
- Исследование Hermes перенесено к файлам и источникам проекта, разбор ошибок — в «Ошибки». Автоповторы доступны в ошибках и настройках перевода, независимо от плагина.
- Добавлены постоянные подписи полей, компактные доступные переключатели, объяснения недоступности действий и отдельные имена диалогов. Проверены поиск и фильтры на 100 тестовых записях, сохранение прокрутки, фокуса и черновиков.

## 0.5.0 — 2026-10-25

- Добавлен необязательный Hermes Agent: включение, отдельное скачивание, модель Ollama, проверка подключения, журнал и остановка в «Настройки приложения → Плагины». Среда плагина сохраняется отдельно от обновляемых файлов программы.
- «ИИ-помощник» проекта исследует расположение текстов и объясняет ошибки через ограниченный MCP только для чтения. Отчёты разделены по проектам; доступ к терминалу и изменению игровых файлов не выдаётся.
- Агенту требуется поддержка инструментов и контекст не менее 64 000 токенов. Настройка агента отделена от контекста перевода; исследование и перевод не используют модель одновременно.
- Автоматическое восстановление ошибок памяти и лимитов включается отдельно для проекта и работает без Hermes. До двух дополнительных проходов подбирают параметры только для неудачных строк; ручные правки, сохранённые оригиналы, паузы и аварийные остановки защищены.
- Загрузка плагина и исследования не открывают консоль. Настройки не теряют черновик и фокус при обновлении состояния.

## 0.4.5 — 2026-10-25

- Ручное подтверждение «Сохранить оригинал» теперь одновременно снимает «Ручную проверку»: строка исчезает из этой папки и остаётся в «Оригинал без перевода» с указанной причиной.
- При открытии исправляются старые автоматические языковые пометки, оставшиеся до сохранения оригинала. Более поздние и неподтверждённые ручные пометки не снимаются автоматически.
- В сохранённых оригиналах доступна кнопка «Снять пометку» для явного решения оставшихся случаев. Пометки «Брак» сохраняются, пока пользователь сам их не снимет.

## 0.4.4 — 2026-10-25

- Встроенные обновления скачивают только изменённые файлы. Неизменённая Lingua и остальные библиотеки проверяются по SHA-256 и используются с диска; отсутствующие или повреждённые файлы автоматически загружаются.
- В окне обновления показываются реальный объём загрузки и объём повторно используемых файлов. Проверка списка файлов, сжатых загрузок и готовой сборки выполняется до замены установленной программы.
- Сохранены резервная копия, откат при сбое установки, пользовательские данные и состояние очереди. Скрытый экземпляр остаётся скрытым после обновления.
- Фоновое обновление карточек больше не сбрасывает фокус и выделение в поле причины сохранения оригинала; черновик причины сохраняется при обновлении карточки.
- Быстрый выбор «Другой язык» / «Авторский приём» заполняет причину. Для сохранения оригинала добавлена отдельная явная кнопка.
- В Releases публикуются полный ZIP для первой установки и файлы для обновлятора. Переход со старого обновлятора на 0.4.4 требует одного полного архива; следующие обновления используют отдельные файлы.

## 0.4.3 — 2026-10-24

- HTTP 500 при выполнении локального запроса Ollama отправляет проблемную строку в «Ошибки», а перевод продолжает со следующей строки. Отключение сервиса и временная недоступность по-прежнему сохраняют очередь на паузе.
- Ошибка нехватки памяти показывается понятным сообщением; для строки сохраняется оценка бюджета и возможность повторить её с другими параметрами контекста и ответа.
- Ошибка Ollama внутри HTTP 200 также распознаётся как неудачный запрос, а не ответ с переводом. Тело ответа провайдера в журнал не копируется.

## 0.4.2 — 2026-10-22

- Перевод, анализ и редактура из приложения запускаются без отдельной консоли; прогресс и журнал остаются внутри окна. Отдельный Ren’Py CLI сохраняет видимый PowerShell.
- Неожиданное завершение обработчика сразу переводит задачу на паузу с сохранением очереди. После перезапуска приложения зависшие признаки работающего обработчика проверяются по реальному процессу.
- Карточка строки больше не показывает «Модель работает…» после остановки; пауза и завершение текущего запроса отображаются отдельно.
- Продолжение заблокировано, пока предыдущий обработчик действительно не завершился; завершение старого запуска не меняет статус нового. Отдельные PID запускателя и обработчика Python корректно учитываются.

## v0.1.0 — 2026-10-06

Первый публичный предварительный релиз Windows x64.

- Настольный интерфейс WebView2 с локальным переводом и редактурой через Ollama.
- Необязательная проверка через облачный API и MCP sampling.
- Возобновляемые проекты и очереди, история, контекст, ручные правки и независимые пометки.
- Обработка длинных строк, повтор ошибок с отдельными параметрами, сохранение символов и иноязычных реплик.
- Папка сохранённых оригиналов: перевод в конец очереди, обработка следующей, ручной перевод с контекстом.
- Выбор закрытия в трей или с остановкой процесса.
- 135 автоматических тестов и проверка интерфейса собранного EXE.

Известные ограничения: поддержка игровых форматов и обратной интеграции неполная; экспорт и литературное качество требуют проверки человеком.
