# Изменения

## 0.4.2 — 2026-10-22

- Перевод, анализ и редактура из приложения запускаются без отдельной консоли; прогресс и журнал остаются внутри окна. Отдельный Ren’Py CLI сохраняет видимый PowerShell.
- Неожиданное завершение обработчика сразу переводит задачу на паузу с сохранением очереди. После перезапуска приложения зависшие признаки работающего обработчика проверяются по реальному процессу.
- Карточка строки больше не показывает «Модель работает…» после остановки; пауза и завершение текущего запроса отображаются отдельно.
- Продолжение заблокировано, пока предыдущий обработчик действительно не завершился; завершение старого запуска не меняет статус нового. Отдельные PID запускателя и обработчика Python корректно учитываются.

## 0.4.1 — 2026-10-18

- MCP `app_ui_state` читает живой интерфейс, `app_screenshot` получает свежий PNG непосредственно из WebView2. Запросы не активируют окно и не используют мышь или системные клавиши.
- CLI `LocalizationWorker.exe --inspect state|screenshot` использует тот же защищённый локальный канал; ключи скрываются в структурированном состоянии.
- Режим `--hidden` запускает приложение в трее без перехвата фокуса и позволяет проверять интерфейс в скрытом тестовом экземпляре.

## 0.4.0 — 2026-10-18

- Рабочее окно разделено на навигацию проекта, текст и текущую задачу; параметры проекта вынесены в отдельное окно с разделами.
- Лимиты одного запуска остаются рядом с запуском; подключения и технические параметры находятся в дополнительных разделах.
- Объяснения доступны через «?» при наведении, фокусе с клавиатуры и нажатии. Зависимые настройки раскрываются по выбранному режиму.
- Настройки можно сохранить или отменить; клавиша Escape возвращает несохранённые параметры. Выбор облака скрыт до его явного включения.

## 0.3.2 — 2026-10-18

- Облачные модели включаются отдельно в «Дополнительно: облачные модели»; по умолчанию доступен локальный режим.
- Отключение облака скрывает его подключение и облачную проверку, сохраняя введённые параметры.

## 0.3.1 — 2026-10-12

- Запуск PowerShell с разрешением исполнения только для отдельного процесса, без изменения системной политики.
- Ошибка запуска или отсутствие подтверждения обработчика переводят задачу на паузу с сохранением очереди вместо бесконечного «Запуск задачи».
- Запоздавший обработчик не запускает задачу, уже поставленную на паузу или отменённую.
- Кнопка анализа показывает провайдера и модель, выбор исполнителя сохраняется в настройках проекта.

## 0.3.0 — 2026-10-12

- Предварительный ИИ-анализ импортированного проекта: персонажи, отношения, термины и сведения о сценах с проверяемыми цитатами оригинала.
- Автоматический подбор справочника к переводу и редактуре, отдельная проверка неясных мест, подтверждение, исправление и отклонение выводов.
- Цепочка «анализ → перевод», сохранение результатов анализа и продолжение по кэшу; устаревшие сведения исключаются из контекста.
- Задачи открывают видимый PowerShell через общий запускатель и оставляют итог DONE/INCOMPLETE на экране.
- Совместимость с прямым Venice API: max_completion_tokens, отключение дополнительного системного текста Venice и веб-поиска.

## 0.2.9 — 2026-10-07

- Ошибки открываются отдельным разделом проекта с постраничным просмотром.
- Закрытие формы повтора сохраняет список ошибок и его прокрутку. Обновление прогресса не пересоздаёт неизменившийся список.

## 0.2.8 — 2026-10-07

- В папках «Брак» и «Ручная проверка» параметры редактуры открываются только по отдельной кнопке в модальном окне.
- Обновление прогресса больше не раскрывает настройки. После закрытия окна общие настройки возвращаются на своё место.

## 0.2.7 — 2026-10-07

- В настройки добавлены ссылки на GitHub Issues, исходный код и инструкцию.
- Блок «О приложении» показывает текущую версию. Ссылки открываются в системном браузере только по нажатию.

## v0.2.6 — 2026-10-07

- Ручная проверка снимает пометки брака и отложенной проверки; строка остаётся видна до выхода из папки.
- Отмена проверки сохраняет текст, восстанавливает предыдущий этап и пометку.
- Кнопка сохранения появляется после изменения текста; проверенные строки показывают только актуальные действия.
- Исправлены старые пометки, сохранённые до ручной проверки; пометки, поставленные после неё, сохраняются.

## v0.2.5 — 2026-10-07

- Удалены отдельная легенда цветов и кнопка «Статусы строк»; подписи статусов остаются на карточках и в фильтрах.
- Удалены неиспользуемые стили точек легенды.

## v0.2.4 — 2026-10-07

- Кнопка «Обновить» и пояснение об источнике показываются только при наличии новой версии.
- Исправлено расположение чекбоксов; кнопка закрытия настроек не прокручивается.

## v0.2.3 — 2026-10-06

- Общее состояние интерфейса имеет одного владельца.
- Удалены цепочки подмены навигации и перелистывания.
- 177 автоматических тестов и 123 проверки собранного интерфейса.

## v0.2.2 — 2026-10-06

- Соединение с резервной копией базы явно закрывается до запуска установщика.
- Добавлена проверка сохранения очередей и их параметров при запуске обновления.

## v0.2.1 — 2026-10-06

- Закреплены окончания строк UI, чтобы Windows checkout не нарушал проверку форматирования и публикацию релиза.

## v0.2.0 — 2026-10-06

- Обновления через GitHub Releases: проверка, скачивание с SHA-256, установка с перезапуском. Автоматические действия отдельно включаются в настройках и по умолчанию выключены.
- Очереди сохраняются; работающие задачи возобновляются с прежними параметрами. База и файлы приложения резервируются, при ошибке установки файлы восстанавливаются.
- Публикация проверенных Windows-сборок из тегов через GitHub Actions. Отдельный установщик проверен на нейтральном проекте: ожидание закрытия GUI, замена файлов, сохранность данных и перезапуск.

- Лимит нового запуска находится в его настройках; параметры продолжения отделены и показываются у задачи на паузе. Текущий запуск показывает обработанные строки или время из заданного лимита и остаток. Продолжение начинает новый отсчёт, сохраняя настройки будущих новых задач.
- Разделены HTTP-транспорт, реестры чтения и команд, запуск задач, схема базы и извлечение текста. Тесты, интерфейс и описание сборки вынесены в отдельные каталоги.
- Убраны цепочки переопределений обновления, отрисовки, настроек и загрузки карточек. Фоновое обновление списка выполняет один запрос; загрузка UI начинается после регистрации модулей.
- Добавлены архитектурные проверки, проверки HTTP-защиты и регрессия завершения обработчика. Форматирование Python и UI закреплено в CI; опубликовано ревью с оставшимися ограничениями.
- Устранена ложная ошибка доступа, когда обработчик завершался перед принудительной остановкой; настоящий отказ в доступе по-прежнему отображается.
- Пояснения цветов перенесены в отдельное окно «Статусы строк». Настройки закрытия показывают текущее действие; кнопка «Снова спрашивать при закрытии» явно объясняет сброс сохранённого действия.
- Повтор ошибок отдельными очередями с собственной моделью и параметрами; очереди запускаются по порядку и сохраняются при закрытии.
- Массовый повтор всех ошибок выбранного этапа, включая записи за пределами страницы, без дублей и перезаписи ручных правок.
- Автоматическая оценка контекста в окне параметров и ручной перевод ошибки вместе с контекстом.
- Раздельные блоки задачи и настроек, отдельное окно управления проектами, раскрываемые превью текста без внутренних полос прокрутки.
- 174 автоматических теста; интерфейс проверен в собранном Windows EXE на нейтральном корпусе и после установки.

## v0.1.0 — 2026-10-06

Первый публичный предварительный релиз Windows x64.

- Настольный интерфейс WebView2 с локальным переводом и редактурой через Ollama.
- Необязательная проверка через облачный API и MCP sampling.
- Возобновляемые проекты и очереди, история, контекст, ручные правки и независимые пометки.
- Обработка длинных строк, повтор ошибок с отдельными параметрами, сохранение символов и иноязычных реплик.
- Папка сохранённых оригиналов: перевод в конец очереди, обработка следующей, ручной перевод с контекстом.
- Выбор закрытия в трей или с остановкой процесса.
- 135 автоматических тестов и проверка интерфейса собранного EXE.

Известные ограничения: поддержка игровых форматов и обратной интеграции неполная; экспорт и литературное качество требуют проверки человеком.
