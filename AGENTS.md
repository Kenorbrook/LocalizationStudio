# Работа с Localization Studio

- После завершённых и проверенных изменений делать коммит и пуш в GitHub: пользователь разрешил это для проекта.
- После работы удалять созданные одноразовые скрипты, временные сборки и тестовые проекты. Повторно используемые инструменты хранить в `tools`, итоговые локальные отчёты — в `reports`.
- Сохранять данные проектов, кэш переводов, резервные копии, журналы работающих задач и опубликованные сборки. Не удалять файлы работающего приложения и обработчика.
- Перед рекурсивным удалением проверять абсолютный путь внутри проекта; не проходить через ссылки и junctions. Тестовый процесс сначала завершить.
- Для интерфейса проверять собранный EXE на нейтральных тестовых фразах. Реальные игровые проекты не использовать для разрушительных проверок.
